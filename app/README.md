# SCP Mobile (Android)

Kotlin + Jetpack Compose app that opens an interactive SSH shell through the gomobile
binding `scpmobile.aar` (`DialDirect` → `OpenShell`).

## Build

Requires JDK 21 and the Android SDK (platform 37, build-tools 37; `sdk.dir` in `local.properties` or `ANDROID_HOME`).

```sh
cd app
./gradlew :app:testDebugUnitTest   # JVM unit tests (no device, no native library)
./gradlew :app:assembleDebug
```

`scpmobile.aar` ships `libgojni.so` for **arm64-v8a only** (`abiFilters` matches), so run on an
arm64 device; x86_64 emulators won't load it. The AAR is consumed from `app/libs/scpmobile.aar`
(`scpmobile-sources.jar` alongside it documents the API).

## Layout (`app/src/main/kotlin/run/scp/mobile/app`)

- `tofu/` – trust-on-first-use: `FileKnownHostsStore` (keyed by the server's real `host:port`),
  `TofuHostKeyDecider`. Unknown or changed keys need an explicit decision and are persisted only when
  accepted; timeouts and UI failures reject. A changed key is shown as a warning, not auto-accepted.
- `terminal/TerminalBuffer` – small line-oriented renderer (CR/LF/BS/TAB, cursor left/right, erase in
  line; other escapes dropped). **Full-screen programs (vim, htop) are not supported yet.**
- `session/` – `SessionViewModel` owns one shell, the TOFU prompt and the terminal snapshot; shell I/O
  runs through an ordered per-connection queue off the main thread. `ShellConnector` is the seam that
  keeps this testable without the native library.
- `ssh/` – `OpenShellConnector` (AAR adapter) and `KeystoreDeviceIdentity` (Ed25519 key generated by the
  AAR, stored AES-GCM-encrypted under an Android Keystore key; the public line is shown on the connect
  screen for `authorized_keys`).
- `ui/` – Connect, Connecting, TOFU and Terminal screens (Compose).

Only direct TCP transport is wired; Boundary transport (`Conn`) is not yet.
