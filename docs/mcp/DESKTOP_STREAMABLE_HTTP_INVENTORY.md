Status: source inventory complete for the 40 existing tools; proposed classifications and contracts require Slice 1 review. No application operations were executed. Baseline: `e9e843092` plus the documentation split already present in the working tree; assessed 2026-11-11.

This is the Slice 0 inventory for [the desktop transport plan](DESKTOP_STREAMABLE_HTTP_PLAN.md). `E` denotes an existing helper command; `P` is a proposed Work 3 shell mapping, not an implemented CLI command. All desktop long-running work remains app-owned. A future one-shot CLI cannot implement persistent start/stop through separate invocations without a daemon; the mappings marked stdio runtime are scoped accordingly.

## Schema work for Slice 1

Current descriptors have no `inputSchema`/`outputSchema`. The table records dispatch behavior, not finalized standard MCP schemas. Slice 1 must define bounded public input DTOs, unknown-field rejection for mutations, object-shaped structured results portable to both target revisions, and safe output DTOs. Arrays/null/scalars shown above are the current `data` payload; standard MCP may wrap them in a named object while REST retains its envelope. Do not reuse secret-bearing `AppConfig`/`SyncSettings` as public output types.

- `FunctionStatus`: `functionId`, `state`, `message`, nullable `boundaryTokenSource`/`sessionId`, `updatedAtMs`. Messages need sanitization; filter deleted-server/stopped-server rows consistently with desktop requirements.
- `StartFunctionResult`: `functionId`, `sessionId`. Accepted/running/completed distinction and readiness semantics must be added deliberately; current wrapper labels every successful dispatch “completed.”
- `Server`: metadata (`id`, `name`, `host`, `os`, `connectionMethod`, `sshPort`, `sshUser`, `boundaryTargetId`, `boundaryListenPort`, `services[{name,port}]`). No SSH password field.
- `RemoteBrowseSession`: `browserId`, `rootPath`; entries: `name`, `path`, `kind`; stat: `path`, `kind`, `exists`.
- `ScpTransferEntry`: `id`, `title`, `detail`, `state`, timestamps, nullable `progressPercent`, `source`, `destination`, `sessionId`. Async tools currently expose only sessionId; correlate to transfer ID explicitly without breaking REST.
- `ConfigPaths` currently contains **only** `appConfigPath`; do not promise a directory inventory.
- All current successful calls use `ok/message/data/warnings/timestamp`; errors are strings, converted by HTTP to a 400 envelope. Separate protocol/transport/tool/resource errors in the new adapter.

## Source findings and implementation risk

1. `is_sensitive_tool` currently marks only 11 tools sensitive; tunnel/SSH/Caddy starts/stops, browser creation/mkdir, and config writes are outside that list. This inventory proposes a conservative sensitivity review of all mutations/launches. Preserve tool names, but document intentional policy corrections on REST too.
2. Unknown policy strings fall through the current exact-string comparison. Tool discovery returns all descriptors, independently of allowed categories; execution checks categories. Unknown tool/category handling must become explicit and fail closed.
3. `redact_sync_settings_value` masks only `mcpAuthToken`; `SyncSettings` also carries CC credentials. Replace broad serialization with safe DTOs before making the standard endpoint usable.
4. `sync_settings_save_partial` accepts the full local patch type, including MCP/CC control fields. Full/partial config writes and sync/git actions require staged protected-field and executable-path review; category permission must not grant policy/identity authority.
5. Dimension extraction casts arbitrary unsigned values to `u16`, silently truncating overflow. Several optional wrong-type values silently default. Define bounded validation rather than copying these behaviors into schemas.
6. Helper `boundary login start --hidden` sends `{hidden:true}`, but the MCP dispatcher ignores it. Do not advertise this as verified automated-OIDC selection; characterize and decide the corrected contract.
7. Current function-status MCP reads access the raw store, while the desktop wrapper applies its own path. Verify filtering and status parity before publishing a canonical schema.
8. Sync SCP calls block until finished and return result text; PTY-backed starts return a session ID before eventual completion. Cancellation and accepted-operation ownership need per-family tests, not just a transport-level abort test.

No existing production symbol is edited in Slice 0. `call_mcp_tool` is called by HTTP dispatch, resource reads, and Tauri `mcp_call_tool_command`; resource reads also have HTTP and Tauri entry points. Later changes have a broad contract surface across these paths, the helper, and CC/admin-driven runtime state. Run impact/uses/affected checks immediately before those edits.
