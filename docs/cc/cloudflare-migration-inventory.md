# cc-server Cloudflare Migration Inventory

Snapshot date: 2026-04-29.

This inventory supports `docs/cc/cloudflare-migration-plan.md` and should be kept current as migration phases change contracts.

## Current backend runtime assumptions

- Runtime: NestJS on Node/Express.
- Static assets: backend serves `public/` and `public/admin-next`.
- Database: local SQLite through native `better-sqlite3`.
- Live transports:
  - agent WebSocket at `/agent`
  - admin PTY WebSocket at `/admin/ws/pty`
  - SSE streams for devices, logs, commands, and transfers
- Auth modes:
  - agent bearer token
  - admin cookie session + CSRF
  - admin bearer token / env token with scopes

## Migration notes

- D1 access is async; existing synchronous store methods should be replaced behind async Worker-specific repositories instead of reusing `better-sqlite3` stores.
- In-memory session maps in `DeviceStore`, `AgentGateway`, `PtyGateway`, and `PtyHubService` need Durable Object equivalents.
- SSE streams currently depend on RxJS Subjects; Worker implementation needs streaming responses, Durable Object fanout, or an explicit contract change.
