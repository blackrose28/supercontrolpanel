Application and Function Config

Paths and username are saved in a local config file. OpenVPN password and OTP secret are stored in the OS secure store (Windows Credential Manager, macOS Keychain, Linux Secret Service).

Config sync (Git repo)

Use a private Git repo (optionally inside Google Drive/OneDrive/Dropbox) as the shared source of truth for config.json. These helpers copy between the app’s config directory and app-config/config.json in your repo.
